# Panopto-Downloader
A tampermonkey (web extension) userscript which downloads Panopto videos.

### Install Instructions
Firefox: https://addons.mozilla.org/en-GB/firefox/addon/tampermonkey/ <br>
Chrome/Chromium based browsers (e.g Brave, Opera GX, etc...): https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo?hl=en <br>
(If you have any problems in relation to installing the extenstion, consult; https://www.tampermonkey.net/index.php?locale=en) <br>
<br>
**Actually installing the userscript:** <br>
After installing the extensions from above, restart your browser and then go to the following URL and hit install:<br>
https://raw.githubusercontent.com/zoroaster1x/Panopto-Downloader/main/Panopto%20Video%20Downloader-1.5.user.js <br>

After that, you may go to your school/university's page for Panopto and click on a video. <br>
You should then see a new "Downloader" icon in the side bar <br>
E.g <br>
<img width="118" height="189" alt="image" src="https://github.com/user-attachments/assets/efac6e6e-a28a-481e-be7a-65944c13d005" /> <br>
